# Employee Management System (CRUD Dashboard)

A full-stack **Employee Management System** that allows users to **Create, Read, Update, and Delete (CRUD)** employee records with a clean **dashboard UI**.  
The frontend is built using **React.js & Tailwind CSS**, and the backend is powered by **Spring Boot (REST API)**.

---

## 🚀 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Spring Boot
- Spring Data JPA
- Spring Web
- Hibernate
- MySQL / PostgreSQL

### Tools
- Maven
- Node.js
- Git & GitHub

---

## ✨ Features

- Add new employee
- View employee list (dashboard)
- Update employee details
- Delete employee records
- RESTful API integration
- Responsive UI with Tailwind CSS
- Clean MVC architecture
- Separate frontend & backend
